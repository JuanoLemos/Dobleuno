## Atribuciones

### Código y assets propios

- Branding "2·1" (heater shield): diseño propio.
- Paleta de colores y tipografía: inspiradas en heráldica medieval y la estética de Old World.
- Nombre "Dobleuno": del autor.

### Contenido de reglas (terceros)

- **Reglas de Warhammer: The Old World** (reglamento, erratas, FAQs, datos de unidades): propiedad de Games Workshop. Dobleuno parafrasea y codifica estas mecánicas en datos estructurados, **no reproduce texto literal extenso**.
- **Mirror de [tow.whfb.app](https://tow.whfb.app/)** — sitio comunitario que mantiene un mirror de las publicaciones oficiales de Games Workshop para TOW. Dobleuno usa este mirror como fuente primaria (ver `doc/Sources.md`). El contenido scrapeado se usa en runtime y cache local de Dobleuno, **no se redistribuye** en este repositorio ni se commitea al código fuente.

### Stack open source

Dobleuno está construido sobre, entre otros:

Vite, React, Tailwind CSS, Drizzle ORM, better-auth, Dexie, Zustand, Zod, react-router, react-intl, Express, pg (node-postgres), OpenAI SDK, Cheerio, ESLint, Prettier, TypeScript, Vitest, Testing Library.

Cada dependencia mantiene su propia licencia (MIT o Apache 2.0 típicamente) en sus respectivos repos.

### Modelos de IA

- **DeepSeek** ([platform.deepseek.com](https://platform.deepseek.com/)) — modelos V3 / R1 / V4.
- **OpenAI** ([platform.openai.com](https://platform.openai.com/)) — embeddings `text-embedding-3-small`.
